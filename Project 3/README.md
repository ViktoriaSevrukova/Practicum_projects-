 **Часть 1. Исследовательский анализ данных**
 
Команде игры «Секреты Темнолесья» важно знать, какая доля игроков покупает внутриигровую валюту за реальные деньги, то есть долю платящих игроков. Их также интересует, как игроки совершают внутриигровые покупки. В этой части проекта нам предстоит написать несколько запросов, которые можно разделить на две задачи.


**Задача 1. Исследование доли платящих игроков**


Изучучим, какую долю составляют игроки, которые купили внутриигровую валюту «райские лепестки» за реальные деньги, от общего количества зарегистрированных игроков. После этого проанализируем, существует ли взаимосвязь доли платящих игроков от выбранной расы персонажа.


Напишим два SQL-запроса:


1.Рассчитаем долю платящих игроков по всем данным и выгрузим несколько полей:
   
a. общее количество игроков, зарегистрированных в игре;

b. количество платящих игроков;

c. доля платящих игроков от общего количества пользователей, зарегистрированных в игре.

3.	Изучим, зависит ли доля платящих игроков от выбранной расы персонажа. Выведим следующие значения для каждой расы персонажа:
   
 a. раса персонажа;
 
 b. количество платящих игроков этой расы;
 
 c. общее количество зарегистрированных игроков этой расы;
 
 d. доля платящих игроков среди всех зарегистрированных игроков этой расы.

Информация о покупке находится в поле payer, в котором 0 означает, что игрок не покупал внутриигровую валюту, а 1 — что покупал. Если посчитать сумму по столбцу payer, то она будет соответствовать общему количеству платящих игроков, а если посчитать среднее значение, то отражать долю таких игроков.
При расчёте доли платящих игроков в разрезе каждой расы считаем долю от общего количества зарегистрированных игроков с персонажем определённой расы.


**Задача 2. Исследование внутриигровых покупок**


Изучим внутриигровую активность игроков по покупке эпических предметов за счёт игровой валюты «райские лепестки» и напишим несколько запросов:
•	Получим основные статистические показатели по полю покупки amount, включая: 

o	общее количество покупок;

o	суммарную стоимость всех покупок;

o	минимальную и максимальную стоимость покупки;

o	среднее значение, медиану и стандартное отклонение стоимости покупки.

•	Проверим, встречаются ли покупки с нулевой стоимостью. Если да, найдем их абсолютное количество и долю от общего числа покупок. Покупки с нулевой стоимостью не помогают зарабатывать внутриигровую валюту «райские лепестки», и их следует исключить при решении следующих задач.

•	Изучим популярность эпических предметов. Для каждого предмета посчитаем: 

o	Общее количество внутриигровых продаж в абсолютном и относительном значениях. Относительное значение должно быть долей продажи каждого предмета от всех продаж.

o	Долю игроков, которые хотя бы раз покупали этот предмет, от общего числа внутриигровых покупателей.
Результат отсортируем по популярности эпического предмета среди игроков. Убедимся, что при написании запроса была проведена фильтрация покупок с нулевой стоимостью.

**Часть 2. Решение ad hoc задач**


В этой части нам предстоит решить ad hoc задачу от маркетинговой команды и коллег из аналитического отдела.


**Задача: Зависимость активности игроков от расы персонажа**


Коллеги из аналитического отдела хотят изучить активность игроков при покупке эпических предметов в разрезе разных рас персонажей. У коллег есть гипотеза, что игра за некоторые расы сложнее и требует большего количества покупок эпических предметов, которые помогают в прохождении. Коллеги стремятся убрать различия в прохождении игры между расами так, чтобы не было рас с лёгким прохождением и, наоборот, — с трудным. 
Чтобы ответить на вопрос коллег, посчитаем такие показатели для каждой игровой расы:

•	общее количество зарегистрированных игроков;

•	количество игроков, которые совершают внутриигровые покупки, и их доля от общего количества зарегистрированных игроков;

•	доля платящих игроков среди игроков, которые совершили внутриигровые покупки;

•	среднее количество покупок на одного игрока, совершившего внутриигровые покупки;

•	средняя стоимость одной покупки на одного игрока, совершившего внутриигровые покупки;

•	средняя суммарная стоимость всех покупок на одного игрока, совершившего внутриигровые покупки.

Убедитимся, что при написании запроса была проведена фильтрация покупок с нулевой стоимостью.

Декомпозируем задачу на несколько подзадач, которые можно решить в виде обобщённых табличных выражений:

1.	Сначала для каждой расы посчитаем общее количество зарегистрированных игроков.
	
2.	Затем для каждой расы посчитаем количество игроков, которые совершили внутриигровую покупку, и долю платящих игроков среди них.
   
3.	Потом соберем информацию об активности игроков, совершивших внутриигровую покупку, с учётом расы персонажа.
   
4.	В итоговом запросе посчитаем необходимые значения.
