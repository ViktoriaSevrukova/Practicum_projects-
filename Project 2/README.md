Таблица **advertisement**


Содержит информацию об объявлениях:


  •	id — идентификатор объявления (первичный ключ).

  
  •	first_day_exposition — дата подачи объявления.

  
  •	days_exposition — длительность нахождения объявления на сайте (в днях).

Таблица **flats**


Содержит информацию о квартирах:


  •	id — идентификатор квартиры (первичный ключ, связан с первичным ключом id таблицы advertisement). 

  
  •	city_id — идентификатор города (внешний ключ, связан с city_id таблицы city).

  
  •	type_id — идентификатор типа населённого пункта (внешний ключ, связан с type_id таблицы type).

  
  •	total_area — общая площадь квартиры, в кв. метрах.

  
  •	rooms — число комнат.

  
  •	ceiling_height — высота потолка, в метрах.

  
  •	floors_total — этажность дома, в котором находится квартира.

  
  •	living_area — жилая площадь, в кв. метрах.

  
  •	floor — этаж квартиры.

  
  •	is_apartment — указатель, является ли квартира апартаментами (1 — является, 0 — не является).

  
  •	open_plan — указатель, имеется ли в квартире открытая планировка (1 — открытая планировка квартиры, 0 — открытая планировка отсутствует).

  
  •	kitchen_area — площадь кухни, в кв. метрах.

  
  •	balcony — количество балконов в квартире.

  
  •	airports_nearest — расстояние до ближайшего аэропорта, в метрах.

  
  •	parks_around3000 — число парков в радиусе трёх километров.

  
  •	ponds_around3000 — число водоёмов в радиусе трёх километров.

**Задача 1. Время активности объявлений**


Чтобы спланировать эффективную бизнес-стратегию на рынке недвижимости, заказчику нужно понять, какие типы квартир Санкт-Петербурга и городов Ленинградской области продаются быстро, то есть объявления о них быстро снимаются, а какие — долго остаются активными на площадках.
Детализация задачи
Время активности объявления или длительность публикации объявления — это количество дней с момента публикации объявления до момента снятия объявления.
Разделим объявления на категории по количеству дней активности: 
•	1-30 days — около одного месяца;
•	31-90 days — от одного до трёх месяцев;
•	91-180 days — от трёх месяцев до полугода;
•	181+ days — более полугода
Объявления, которые не были сняты с продажи, объединим в категорию non category. 
Для каждой категории изучим количество продаваемых квартир, а также их параметры, включая среднюю стоимость квадратного метра, среднюю площадь недвижимости, количество комнат и балконов. Сравним объявления Санкт-Петербурга и городов Ленинградской области.
При работе с данными используеме только объявления о продаже недвижимости в городах за 2015–2018 годы включительно.

**Подсказка**


При решении задачи рекомендуем сначала провести категоризацию объявлений по дням активности, а после этого сгруппировать данные по выделенным категориям с учётом региона и типа населённого пункта.
Когда будем изучать характеристики недвижимости, будем использовать статистические параметры вроде средних значений, медианы или моды.
Чтобы сравнить объявления Санкт-Петербурга и городов Ленинградской области, создадиме поле, категоризирующее объявление: принадлежит ли оно Санкт-Петербургу или городу Ленинградской области. Это поможет решить задачу в один запрос.
«Спасательный круг»
Решить такую задачу получится, если категоризировать данные по двум критериям:
•	время активности объявления;
•	принадлежность объявления к населённым пунктам Ленинградской области или Санкт-Петербургу.

Категоризация по времени активности позволит выделить сегмент недвижимости, который продаётся за короткий период времени, — что явно заинтересует заказчика. А категоризация по региональному признаку поможет сравнить характеристики недвижимости для Санкт-Петербурга и городов Ленинградской области.
При решении задачи разделим её на серию небольших задач и будем используовать отдельные обобщённые табличные выражения (СТЕ). Например:

1.	Отфильтруем данные от аномальных значений, которые обнаружили при исследовании данных. 
2.	В отдельном СТЕ подготовим данные для исследования: выделим категории объявлений и добавим их к основной информации о квартирах. Здесь понадобятся данные о квартирах и о самих объявлениях, — категоризируем эти данные следующим образом (и добавим в выгрузку новые поля):
a. Присвоим категорию Санкт-Петербург, если город объявления соответствует идентификатору Санкт-Петербурга, и категорию ЛенОбл, если недвижимость расположена в другом городе. b. Присвоим категорию по количеству дней активности объявлений. Для этого можно также использовать конструкцию CASE. Объявлениям, которые являются активными, присвоить категорию non category.
3.	В этом же СТЕ можно подсчитать интересующие заказчика параметры вроде стоимости одного квадратного метра недвижимости и отфильтровать данные по типу населённого пункта, оставив только города. Не забудем про фильтрацию объявлений, которые содержат аномальные данные.
4.	Можно начать писать основной запрос. Используя данные последнего СТЕ. Сгруппируем данные по категории «Регион» (Санкт-Петербург или ЛенОбл) и по категории активности объявления. При группировке данных подсчитайте значения, которые помогут ответить на вопросы заказчика и провести сравнительный анализ объявлений Санкт-Петербурга и Ленинградской области. Например:
a. Количество объявлений в каждом сегменте. Полезно подсчитать не только абсолютные значения, но и долю объявлений в разрезе каждого региона. b. Подсчитайте среднюю стоимость квадратного метра и среднюю площадь недвижимости для каждого сегмента. c. Подсчитайте иные характеристики недвижимости, которые покажутся нам интересными, например, долю квартир-студий или среднюю высоту потолка.
В результате у нас должна получиться единая сводная таблица — с усреднёнными характеристиками объявлений для каждого сегмента, выделенного по количеству дней активности, в разрезе Санкт-Петербурга и городов Ленинградской области. 
 
**Задача 2. Сезонность объявлений**


Заказчику важно понять сезонные тенденции на рынке недвижимости всего региона, включая объекты недвижимости Санкт-Петербурга и Ленинградской области, продаваемые в городах. Цель — выявить периоды с повышенной активностью продавцов и покупателей, а также оценить характеристики недвижимости в разные сезоны. Это поможет спланировать маркетинговые кампании и выбрать сроки для выхода на рынок.
Детализация задачи
Для исследования объявлений по периодам будем использовать дату публикации объявления и дату снятия объявления с публикации: можно считать, что снятие объявления часто происходит при продаже недвижимости. В качестве единицы периода используем месяц — это позволит выявить сезонные колебания активности. 
При работе с данными будем использовать только объявления о продаже недвижимости в городах за полные годы — в датасете это 2015–2018 годы. Это позволит избежать искажений из-за неполных лет. 

**Подсказка**


При решении задачи выделим месяц публикации и месяц снятия объявления с продажи. Для расчёта даты снятия с продажи будем используовать количество дней активности объявления: дата_публикации + количество_дней_активности. 
Используем данные за все месяцы 2015–2018 годов и без усреднения по годам — это упростит расчёты. При агрегации данных посчитаем количество объявлений для каждого периода, среднюю стоимость квадратного метра и среднюю площадь недвижимости.
Для решения задачи используем СТЕ. Сначала для каждого объявления за 2015–2018 годы найдием месяц выставления объявления на продажу и месяц его снятия. После этого отдельно посчитаем статистику по месяцу публикации и месяцу снятия объявлений, а в итоговом запросе объединим результаты в одну таблицу. Не забудем провести фильтрацию по типу населённого пункта - анализ следует провести по объявлениям недвижимости, продаваемой в городах.
